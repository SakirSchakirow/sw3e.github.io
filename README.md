# sw3e.github.io

* This is a simple AR web app that uses [MindAR.js](https://hiukim.github.io/mind-ar-js-doc/) to display 3D models on top of a marker card.
* Use https://hiukim.github.io/mind-ar-js-doc/tools/compile to create your own `.mind` marker card
* I use `sw3e-qr.png` as the marker card for this project, which is URL to this GitHub page.
